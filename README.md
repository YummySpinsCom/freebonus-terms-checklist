# FreeBonus Terms Checklist

A simple browser-based checklist for reviewing online casino bonus terms and conditions.

This tool helps users go through the most important conditions of a casino bonus before deciding whether an offer is suitable for them.

## What to Check

- Minimum deposit requirement
- Wagering requirements
- Maximum bonus amount
- Eligible games
- Game contribution rules
- Maximum bet restrictions
- Bonus expiration period
- Withdrawal restrictions

## How It Works

Open the checklist and review each bonus condition.

Mark each item after checking the relevant term. The tool keeps track of your progress so important bonus conditions are less likely to be overlooked.

## Project Files

- `index.html` - checklist interface
- `style.css` - page styling
- `script.js` - checklist functionality
